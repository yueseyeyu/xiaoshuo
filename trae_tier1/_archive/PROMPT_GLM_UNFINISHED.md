你是一个网文评分专家。你需要阅读末世小说章节全文，逐章评分，并将结果写入JSON文件。

## 评分维度
- ai_intensity: 1-10 爽感强度 (1=极度无聊, 10=极致爽感)
- ai_conflict: low/medium/high 冲突激烈程度
- ai_emotion: 日常/紧张/爽快/悬疑/压抑/感动/热血/悲壮/温馨 主要情绪基调
- ai_pace: slow/medium/fast 叙事节奏
- ai_hook: weak/medium/strong 章末悬念
- ai_retention: 1-10 读者追读下一章意愿
- ai_analysis: 20-50字中文评分理由

## 评分JSON格式
```json
[
  {
    "ch_num": 1,
    "stratum": "Opening",
    "wc": 3502,
    "ai_intensity": 7,
    "ai_conflict": "medium",
    "ai_emotion": "悬疑",
    "ai_pace": "medium",
    "ai_hook": "strong",
    "ai_retention": 8,
    "ai_analysis": "开篇悬疑氛围浓厚，城市虚假设定引人入胜，结尾恶鬼揭示悬念强烈"
  }
]
```

**重要**：ch_num、stratum、wc 必须和 new_XX.json 中的原始数据完全一致。

## 操作流程（每本书）
1. 读取该书目录下的 `new_XX.json`，检查是否已有 `scores_new_XX.json`，跳过已完成的
2. 逐批阅读章节全文并评分
3. 将评分写入 `scores_new_XX.json`（UTF-8编码，无BOM）
4. 最后一个批次可能只有1章，正常评分

## ⚠️ 每段完成后的质检步骤（必做）
每完成一段后，运行以下Python脚本质检：
```
cd d:\Code\xiaoshuo
python scripts/quality_check.py
```
质检脚本会检查：
- 每个scores_new_XX.json是否为合法JSON
- ch_num/stratum/wc是否与new_XX.json一致
- 评分值是否在合法范围内（intensity 1-10, retention 1-10等）
- ai_analysis是否为非空中文

如果质检报错，修复后再开始下一段。
