## 二、评分关系审计 (4条链)

### 2.1 Rhythm → LLM强度 传导审计

**核心发现: hook_density vs llm_intensity 相关性偏弱**

| 指标 | 值 |
|------|-----|
| 有效相关系数 | 33/33本 |
| Pearson r 均值 | **0.145** |
| r 范围 | -0.211 ~ 0.555 |
| 正相关书籍 | 27本 |
| 负相关书籍 | 6本 |

**分析:**
- 平均r=0.145属于弱正相关区间(0.1-0.2)
- 这意味着rhythm规则指标(hook_density等)与LLM评分之间仅有微弱关联
- 6本书出现负相关, 说明规则指标和LLM对"爽感"的判断存在分歧
- 可能原因: (1)规则指标捕获的是文本表面特征(如"!"密度), 而LLM捕获的是语义层面的爽感; (2)LLM评分有系统性偏差(Bias=+1.78), 模糊了真实相关性

**评级: WARN** — 传导链存在但弱, 说明规则评分和LLM评分是互补而非冗余的信号源, 这对BMA加权是合理的。

### 2.2 T1 vs T2 一致性审计

**核心发现: T1-T2均值差远小于校准Bias预期**

| 指标 | 实际值 | 预期值(基于Bias) | 差异 |
|------|--------|-----------------|------|
| T1均值 - T2均值 (intensity) | **0.07** | 4.37 | **59倍偏差** |
| T1均值 - T2均值 (retention) | **-0.11** | 5.39 | **49倍偏差** |

**关键分析:**

这是一个**需要深入理解的重要发现**。校准数据显示T1 Bias=+1.78(相对human), T2 Bias=-2.59(相对human), 预期T1-T2差=1.78+2.59=4.37。但实际T1-T2均值差仅0.07。

**原因分析:**
1. **Bias是相对human golden计算的, 不是T1和T2之间的直接差异**。T1 Bias=+1.78意味着T1比human高1.78分; T2 Bias=-2.59意味着T2比human低2.59分。如果T1和T2采样的是**不同章节**, 那么章节本身的强度差异可能抵消了评分偏差。
2. T1采样10%均匀分层(包含高峰和低谷章节), T2按节奏对齐采样(S级采高峰50%)。如果S级书的T2采样偏向高hook章节, 这些章节本身intensity就高, 抵消了T2的低估偏差。
3. **这意味着校准Bias在书籍层面被采样差异掩盖了**——单看T1和T2的均值无法发现Bias, 只有在同一章节上对比T1/T2/human才能发现。

**评级: WARN** — T1和T2在书籍层面看起来一致, 但这是采样偏差和评分偏差互相抵消的结果, 不是真正的系统一致性。

#### 2.3.3 GLM vs T1 相关性 — **循环论证风险确认**

| 指标 | 值 |
|------|-----|
| 重叠章节数 | 95 |
| GLM vs T1 Pearson r (intensity) | **0.590** |
| 判定 | ⚠️ 高度相关 |

**r=0.590意味着GLM和T1评分有35%的共享方差。** 这不奇怪——两者都是AI评分, 对"爽感"的判断标准相似。但问题在于: GLM被当作"校准锚点"来校准T1, 而GLM本身就是AI评分, 这构成了**AI校准AI的循环论证**。

#### 2.3.4 校准结果验证

| 指标 | 30章纯人工 | 125章混合 | 差异 |
|------|-----------|----------|------|
| Pearson r | 0.473 | 0.565 | +0.092 |
| Bias | +1.60 | +1.78 | +0.18 |
| OLS slope | **0.762** | **0.463** | **-0.299** |
| OLS intercept | — | 2.249 | — |

**关键发现: slope从0.762(纯人工)下降到0.463(混合), 降幅39%**

这说明GLM数据的加入**显著改变了校准方向**——使得T1看起来比实际更"通胀"。原因是GLM评分(mean=6.00)比human评分(mean=4.83)更高, 但比T1评分(mean≈7.0)更低, 拉低了回归斜率。

#### 2.3.5 LOOCV统计显著性

| 指标 | 值 |
|------|-----|
| LOOCV n | 125 |
| LOOCV r (intensity) | 0.546 |
| t-statistic | 7.23 |
| df | 123 |
| p-value | <0.001 (threshold≈3.37) |
| LOOCV MAE | 0.97 |

**LOOCV r=0.546统计显著(p<0.001)**, 说明校准模型在留一交叉验证下有预测力。但需要注意: 由于76%的校准数据来自GLM(AI), 这个"预测力"部分反映的是GLM与T1的一致性, 而非真正的人工校准效果。

#### 2.3.6 OLS slope 通胀分析

```
slope = 0.463 意味着: T1每增加1分, human只增加0.463分
T1通胀率 = (1 - 0.463) / 0.463 = 116%
即: T1分数中约54%是"通胀"(虚假高分)
```

**但这个slope=0.463是混合了GLM数据的结果。** 如果仅用30章纯人工数据, slope=0.762, 通胀率仅31%。GLM数据的加入使得T1看起来比实际更不准。

**评级: WARN** — 校准在统计上显著, 但存在系统性偏差来源(GLM自评占76%), 且GLM数据显著改变了校准方向。

### 2.4 LLM评分 → 商业评分 → Borda排名 传导审计

#### 传导链分析

```
rhythm CSV (规则指标)
    ↓
compute_commercial_score()
    ├→ signing_score (基于hook_density, conflict_density等规则指标)
    ├→ retention_score (BMA加权: 规则50% + LLM 50%)
    ├→ diversity_score (爽点多样性, Shannon指数)
    ├→ BT相对排名 (外部数据)
    └→ WebNovelBench综合 (外部数据)
    ↓
Borda Count (5维加权排序)
    signing(0.8) + retention(0.8) + diversity(0.4) + bt_rank(1.5) + webnovel8(1.5)
    ↓
最终排名
```

**关键发现:**
1. signing_score**不直接使用LLM评分**, 而是基于rhythm CSV的规则指标计算 — 这降低了直接循环论证风险
2. retention_score通过BMA权重间接使用LLM评分 — 存在间接传导
3. 外部维度(bt_rank, webnovel8)权重占60%, 是排名的主要驱动力
4. signing#1的末世之深渊召唤师borda#2, 但v8.8已降为A级 — **signing维度高排名不等于高质量**

**评级: PASS(有保留)** — 传导链透明可追溯, 外部维度占主导降低了内部循环论证的影响。

#### 重点质疑1: 长夜余火(borda#15)为何是S级?

**数据层面:**
- Borda排名#15/33, 处于中游偏下

**人工分级依据:** "白金大神, 文学深度+废土公路片"

**审计判断:** 长夜余火的S级分级主要基于**作者知名度(爱潜水的乌贼)**和**文学性主观判断**, 而非数据指标。其外部排名(bt#16, webnovel#16)和内部指标(signing#24)均不支持S级。diversity#5是其唯一亮点。

**风险: 中等** — 作者知名度是合理的质量信号, 但不应凌驾于数据之上。建议降为A级或标注"S*(作者加成)"。

## 四、风险评估 (5项)

### 4.1 循环论证风险

| 维度 | 分析 | 风险级别 |
|------|------|---------|
| signing | 基于rhythm规则指标计算, 不直接使用LLM评分 | 中等 |
| retention | 通过BMA权重间接使用LLM评分(50%权重) | 中等 |
| diversity | 基于rhythm规则指标(Shannon指数), 不使用LLM评分 | 低 |
| bt_rank | 外部数据(BT网站排名), 完全独立 | 无 |
| webnovel8 | 外部数据(WebNovelBench), 完全独立 | 无 |

**综合风险评估: 中等**

- signing虽不直接使用LLM评分, 但rhythm规则指标→LLM评分→retention→Borda存在间接传导路径
- 末世之深渊召唤师signing#1→borda#2但已被降为A级, 证实了signing循环论证的存在
- 外部维度(bt+webnovel8)权重占60%, 是对内部循环的有效制衡

**缓解措施已实施:** v8.7已将signing权重从1.0降至0.8, 外部维度升至1.5。

### 4.2 GLM自评风险

| 指标 | 值 |
|------|-----|
| 校准数据集 | 30章人工 + 95章GLM = 125章 |
| 人工占比 | 24% |
| GLM占比 | **76%** |
| GLM评分者 | CatPaw (AI) |
| 被校准对象 | T1 (AI评分) |
| GLM vs T1相关性 | **r=0.590** |

**风险级别: 高**

这是本次审计发现的最严重系统性风险:
1. **AI校准AI**: GLM(CatPaw)评分被当作"准人工"锚点校准T1(另一个AI), 两者有35%共享方差
2. **GLM改变了校准方向**: 纯人工slope=0.762, 混合后slope=0.463, 降幅39%。GLM数据使得T1看起来比实际更不准
3. **GLM评分均值(6.00)高于人工均值(4.83)**: GLM本身也有高估倾向(Bias=+1.17), 只是没有T1那么高
4. **如果GLM和T1有共同的系统性偏差**(如对战斗场景过度给分), 校准无法发现这种偏差

**改进建议:**
- 扩大人工标注到至少50章(占40%+), 覆盖更多书籍和章节类型
- 引入第二个独立AI评分者(如DeepSeek), 进行AI间交叉验证
- 报告纯人工校准结果作为"严格基线", 混合结果作为"实用基线"

### 4.3 采样代表性风险

| 维度 | 分析 |
|------|------|
| T1采样 | 10%均匀分层, 但实际采样率0.9%-30.6%, 差异巨大 |

| 节奏对齐 | S级T2采高峰50%, 但T2均值仍低于T1 → T2模型严重低估 |

**风险级别: 中等**

- S级书采样密度远高于C级, S级评分更准确但也可能过度代表
- T1采样率不一致(0.9%-30.6%)是数据质量问题, 需要统一
- T2采样高峰章节但均值更低, 说明T2模型(Qwen)的低估是系统性的, 不是采样偏差导致的

## 八、审计结论

### 数据管线机械完整性: ✅ 可信

33本×5层(TXT→Rhythm→T1→T2→LLM)的数据管线完整, 所有CSV文件存在且行数匹配, T1-T2零重叠验证通过, 总计5472章LLM评分数据。这是整个体系的基础, 机械完整性可信。

### 评分校准有效性: ⚠️ 有保留

LOOCV r=0.546统计显著(p<0.001), 校准模型有预测力。但76%的校准数据来自GLM(AI), 与被校准的T1(AI)有r=0.590的相关性, 构成AI校准AI的循环论证。纯人工校准(slope=0.762)与混合校准(slope=0.463)差异显著, GLM数据拉低了slope 39%。

### 排名稳定性: ✅ 可信

Borda排名对权重变化高度稳定(等权vs当前 Spearman r=0.988), 对T2数据去除不敏感(影响≈0.1分/书)。Borda与TOPSIS高度一致(Spearman r=0.917)。排名主要由外部维度(bt_rank, webnovel8)驱动, 降低了内部循环论证的影响。

### 人工分级合理性: ⚠️ 存在矛盾

7本S级书中, 4本(全球变异#1、末世大回炉#3、地球游戏场#4、黑暗血时代#5)与Borda排名一致, 1本(第一序列#8)轻微偏低, **2本(长夜余火#15、末日乐园#23)严重矛盾**。末日乐园的diversity排名倒数第1、webnovel8排名#27, S级分级缺乏数据支撑。长夜余火的S级主要依赖作者知名度。

### 最终判定

**v8.10末世小说分析评分体系总体可信度为中等。** 数据管线完整、排名稳定, 但校准存在GLM自评循环论证风险, 人工分级中2本S级书缺乏数据支撑。建议执行P0级改进措施后重新评估。
