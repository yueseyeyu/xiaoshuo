# 小说排名验证文件体系

## 目录结构

```
data/reports/rankings/
├── README.md                    ← 本文件
├── 末世/
│   ├── v8.8_final_ranking.md    ← v8.8最终分级排名（三方审视后）
│   ├── v8.8_final_ranking.csv   ← CSV格式（供程序读取）
│   ├── v8.7_pre_review.md       ← v8.7三方审视前排名（历史快照）
│   ├── 三方AI审视记录.md         ← DeepSeek/Kimi/Doubao原始审视记录
│   └── 鼻祖效应分析.md           ← "鼻祖效应"偏差分析专题
└── (其他分类待后续添加)
```

## 文件命名规则

- `v{版本号}_final_ranking.md/csv` — 最终确认的排名文件
- `v{版本号}_pre_review.md` — 审视前的历史快照
- `三方AI审视记录.md` — 外部AI原始审视内容存档
- 专题分析文件按需创建

## 核心原则

**文字质量优先**：项目目标是"凝练最好的网文AI"，评级以文字本身质量为第一标准。
- "鼻祖"/"经典"/"开山"标签不自动等于高质量
- 内部指标（hook3/pleasure/retention）天然过滤历史地位偏差
- 2026年节奏标准评判所有书籍，不分年代
