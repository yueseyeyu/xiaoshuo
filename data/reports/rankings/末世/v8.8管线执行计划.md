# v8.8管线执行计划（修正版）— 三层评估体系

> **修正日期**: 2026-07-12
> **修正原因**: 前版方案错误地将Tier2采样量与Tier1覆盖率混淆，现按用户确认的三层架构重新设计

## 一、三层评估体系正确分工

```
┌─────────────────────────────────────────────────────┐
│  Tier 1: AI全读10%分层采样 (ai_annotate.py)          │
│  ├─ 策略: 黄金5层分层(Opening3%/Rising27%/Mid30%     │
│  │        /Climax30%/Ending10%) × 10%采样率          │
│  ├─ 执行者: CatPaw/外部AI（读全文，不截断）            │
│  ├─ 输出: {book}_ai_full.csv                          │
│  └─ 作用: 广覆盖，提供AI视角的全书质量画像              │
├─────────────────────────────────────────────────────┤
│  Tier 2: 本地Qwen按分级+黄金动态滑动 (llm_batch_score) │
│  ├─ 策略: 按quality_tiers分级决定采样量               │
│  │   S=50章×3SC / A=30 / B+=30 / B=30 / B-=30 / C=20 │
│  ├─ 采样: 节奏峰谷对齐(S峰50%/A中30%/B谷20%)+滑动窗口  │
│  ├─ 执行者: 本地Qwen3.5-9B (rubric+CoT评分)           │
│  ├─ 输出: {book}_llm.csv                              │
│  └─ 作用: 深度质量评估，与Tier1交叉验证                │
├─────────────────────────────────────────────────────┤
│  Tier 3: 人工标注—分歧驱动+校准锚点 (three_tier_eval) │
│  ├─ 策略: |Tier1-Tier2|最大分歧章节+固定位置锚点       │
│  ├─ 采样: 5锚点+10分歧+2补充 = ~17章/书               │
│  ├─ 执行者: 人工阅读并评分                             │
│  ├─ 输出: human_golden.csv (累积)                     │
│  └─ 作用: 最终校准基准，消除AI/本地模型系统偏差         │
└─────────────────────────────────────────────────────┘
```

**三层协作关系**：
- Tier1的10%覆盖解决了"广度"问题 → Tier2的S=50不需要再追求10%覆盖
- Tier2的分级采样解决了"深度"问题 → S级50章×3SC已足够深度评估
- Tier3的分歧驱动解决了"校准"问题 → 只标17章即可校准两个模型

## 四、执行顺序建议

```
Phase 1 (规则评分+Borda)     ← 立即执行，不需要LLM
    ↓
Phase 3 (Tier2 Qwen评分)     ← 需要LLM server，可分批跑
    ↓ (与Phase 2并行)
Phase 2 (Tier1 AI全读10%)    ← 需要CatPaw/外部API
    ↓
Phase 4 (Tier3 人工标注)     ← 依赖Tier1+Tier2完成
```

**关键路径**: Phase 1 → Phase 3（Tier2优先，因为本地Qwen可无人值守跑）

**并行路径**: Phase 2（Tier1 AI全读）可与Phase 3并行，但需要外部API额度
